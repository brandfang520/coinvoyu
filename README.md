# CoinVoyu V2

域名：coinvoyu.com

这是一个 Next.js 14 的网站基础版本，已经包含：
- 首页
- 分类页
- 独立文章页
- 基础 SEO metadata
- sitemap.xml
- robots.txt
- 响应式移动端布局
- 新手入门 / 比特币 / 以太坊 / 安全 / 交易平台 / Web3 分类
- 4 篇示例文章

## 本地运行

需要 Node.js 18+：

```bash
npm install
npm run dev
```

然后打开 http://localhost:3000

## 部署

可以直接导入 GitHub 后部署到 Vercel。
部署后把 coinvoyu.com 添加到 Vercel 项目域名设置，并按域名注册商要求配置 DNS。
