# CoinVoyu Taiwan 文章长期模板

本模板只适用于 CoinVoyu Taiwan，不得用于修改 CoinVoyu 简体主站。

## 必备模块

1. 单一 H1、直接回答搜索问题的摘要。
2. 作者、首次发布时间、最后更新时间。
3. 16:9 封面与准确替代文字。
4. 重点整理。
5. 对应 Topic Cluster 或 Conversion Cluster 导航。
6. 正文与实操步骤；仅在教程需要时加入图片或视频。
7. 外部素材来源说明。
8. 官方资料来源与核对日期。
9. 风险提示。
10. 至少三个「继续学习」站内入口。
11. Article、Breadcrumb 与适用时的 FAQPage Schema。

## CTA 分类

- A 类信息型：不放直接注册按钮，以学习内链为主。
- B 类教程型：在理解平台和步骤后自然提供对应平台注册入口。
- C 类商业搜索型：必须提供清晰下一步，但只展示当前语境对应的平台。

台湾站直接注册链接统一来自 `tw/platforms.json`：Binance 与 OKX 使用 `TW1866`，Gate 使用 `VOYUTWFF`。不得读取或使用任何主站推广配置。

## 素材来源

Binance Launch Station 图片、影片和教学资料属于 CoinVoyu Taiwan 可长期调用的教学资源。注册、KYC、安全设置、买币、交易、提币和 App 操作等实操内容，应按文章场景优先评估是否接入；不得为了装饰机械插入。

实际使用时必须注明「图片来源／影片来源：Binance Launch Station 官方教学资源」，或「部分操作示意参考 Binance Launch Station 教学素材」，不得声明为 CoinVoyu 原创。界面或操作流程明显过时时应更新或停止使用。
