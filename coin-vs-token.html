Coin 和 Token 有什么区别？新手一篇看懂

很多新手会把 Coin 和 Token 都叫作“币”，但它们在技术结构和用途上并不完全相同。

作者：CoinVoyu 编辑团队·最后更新：2026-09-17·作者说明·编辑规范

Coin 是什么？

Coin 通常指拥有自己独立区块链网络的原生资产。例如 BTC 运行在 Bitcoin 网络上，ETH 是 Ethereum 网络的原生资产。它们往往用于支付网络手续费、激励网络参与者，或作为网络中的基础资产。

Token 是什么？

Token 通常依托已有区块链发行，本身不需要重新建立一条独立区块链。例如许多代币运行在 Ethereum、BNB Smart Chain 或其他智能合约平台上。不同 Token 可以代表不同用途、权益或链上资产。

为什么新手容易混淆？

交易平台通常把 Coin 和 Token 放在同一资产列表中，买卖体验也很相似，所以日常交流里经常统称为“币”。真正需要注意的是转账时的网络、合约地址和资产标准，不能只看名称。

新手应该记住什么？

判断一个资产时，可以先问三个问题：它有没有自己的区块链？它运行在哪条网络上？转账时需要什么网络手续费？理解这三点，比死记术语更实用。

新手提醒：涉及转账、授权或链上操作时，请先核对网络、地址和官方资料，小额测试后再继续。
