Coin 和 Token 有什么区别？新手一篇看懂

很多新手会把 Coin 和 Token 都叫作“币”，但它们在技术结构和用途上并不完全相同。

Coin 是什么？

Coin 通常指拥有自己独立区块链网络的原生资产。例如 BTC 运行在 Bitcoin 网络上，ETH 是 Ethereum 网络的原生资产。它们往往用于支付网络手续费、激励网络参与者，或作为网络中的基础资产。

Token 是什么？

Token 通常依托已有区块链发行，本身不需要重新建立一条独立区块链。例如许多代币运行在 Ethereum、BNB Smart Chain 或其他智能合约平台上。不同 Token 可以代表不同用途、权益或链上资产。

为什么新手容易混淆？

交易平台通常把 Coin 和 Token 放在同一资产列表中，买卖体验也很相似，所以日常交流里经常统称为“币”。真正需要注意的是转账时的网络、合约地址和资产标准，不能只看名称。

新手应该记住什么？

判断一个资产时，可以先问三个问题：它有没有自己的区块链？它运行在哪条网络上？转账时需要什么网络手续费？理解这三点，比死记术语更实用。

新手提醒：涉及转账、授权或链上操作时，请先核对网络、地址和官方资料，小额测试后再继续。

COIN VS TOKEN

判断 Coin 还是 Token，先看“它依赖哪条链”

比较项CoinToken
基础网络通常是自身区块链的原生资产通常依托现有区块链上的智能合约
网络费用常由该链原生 Coin 支付转移 Token 时通常仍需准备对应网络的 Gas 资产
识别方式重点核对网络除网络外还应核对合约地址
转账风险常见于选错网络或地址还可能出现同名 Token、假合约等问题

实用例子：在 Ethereum 上转移某个 ERC-20 Token 时，即使钱包里 Token 数量足够，也通常仍需要 ETH 支付网络 Gas。

BEFORE YOU TRANSFER

转 Token 前做 4 次核对

  1. 01
    确认网络

    先确认钱包、交易所和接收方支持同一网络。

  2. 02
    确认合约

    不要只凭名称和图标识别 Token，优先核对官方合约信息。

  3. 03
    准备 Gas

    确认钱包里有足够的网络原生资产支付手续费。

  4. 04
    新地址先小额测试

    首次操作时先验证完整路径，再考虑后续转账。

ASSET IDENTITY

看到一个新资产，先用这 5 个问题确认身份

问题为什么要确认
它有没有自己的原生区块链？这是区分原生 Coin 与依赖其他链发行 Token 的核心线索。
它运行在哪条网络？决定转账、钱包支持和网络手续费。
Token 的合约地址是什么？同名、同符号资产可能很多，合约地址更适合核对具体 Token。
手续费使用什么原生资产？持有 Token 不代表一定有足够 Gas 完成链上操作。
平台支持哪条充值/提币网络？资产名称相同也不能忽略网络匹配。
名称相同不等于同一资产优先核对网络与合约，而不是只看简称和 Logo。
Coin 也可能有映射版本跨链后的包装或映射资产可能以 Token 形式存在，需要区分原生资产。

转账前：资产、网络、合约（适用时）和接收方支持范围四项同时匹配，再进行小额测试。
